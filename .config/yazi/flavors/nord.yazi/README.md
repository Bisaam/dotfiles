# nord.yazi

[Nord](https://www.nordtheme.com) for Yazi, kept here in the dotfiles rather
than installed with `ya pkg`.

`flavor.toml` is the official catppuccin-mocha flavor with every color swapped
for its Nord counterpart, so `ya pkg upgrade` changes to that flavor are easy to
carry over. `tmtheme.xml` is the Nord.tmTheme that bat ships
([crabique/Nord-plist](https://github.com/crabique/Nord-plist), MIT, see
`LICENSE-tmtheme`), which keeps code previews identical to `bat` and vim.
